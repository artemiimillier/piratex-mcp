# Piratex: поиск вирусных Reels и TikTok через MCP

[Piratex.ai](https://piratex.ai) помогает русскоязычным авторам, SMM-специалистам и продюсерам находить сильные короткие видео в своей нише, изучать конкурентов и разбирать ролики по ссылке. MCP-сервер передаёт данные в подключённый ИИ: например, Claude, ChatGPT, Claude Code, Cursor или VS Code. Доступность подключения зависит от клиента, тарифа и региона.

**Адрес сервера:** `https://piratex.ai/api/mcp`  
**Транспорт:** Streamable HTTP. **Вход:** OAuth; также доступен личный API-ключ из кабинета Piratex.

## Для каких задач

- Найти Reels в Instagram* и видео TikTok, которые набрали необычно много просмотров относительно других видео того же автора.
- Посмотреть последние ролики публичного автора Instagram или TikTok и сравнить их показатели.
- Разобрать доступное видео по ссылке: метрики, речь с таймкодами, хук, сцены, ключевые кадры и комментарии. Разбор по ссылке поддерживает в том числе YouTube и Shorts; поиск трендов по нишам относится к Instagram и TikTok.
- Передать полученные данные своему ИИ для анализа и подготовки собственных идей и сценариев.

Piratex предоставляет данные; выводы и текст формирует ваш ИИ. Сервис не гарантирует вирусность будущего ролика. Полнота разбора зависит от доступности исходного контента.

## Инструменты

| Инструмент | Задача |
|---|---|
| `trending_now` | Найти ролики в нише с показателями относительно обычных просмотров автора |
| `niche_search` | Найти нишу в каталоге |
| `set_my_niches`, `my_profile` | Сохранить и прочитать собственные ниши |
| `get_profile` | Получить информацию о публичном авторе и последних видео |
| `xray_video` | Разобрать видео по ссылке |
| `account`, `credit_history` | Проверить баланс и историю операций |

«x к медиане» означает отношение просмотров ролика к медиане просмотров выборки последних роликов автора. Например, 80 тысяч просмотров при медиане 10 тысяч дают x8. Это сравнительный показатель, а не прогноз роста. Данные отражают время последнего сбора, а не непрерывное наблюдение в реальном времени.

## Подключение

Создайте аккаунт на [piratex.ai](https://piratex.ai). В клиенте с поддержкой удалённого MCP добавьте адрес сервера, выберите OAuth, войдите в Piratex и подтвердите доступ. Наличие публичной записи в реестре не означает одобрение в каталоге Claude или ChatGPT.

### Claude Code

```bash
claude mcp add --transport http piratex https://piratex.ai/api/mcp
```

Затем откройте `/mcp` и завершите вход.

### Claude и ChatGPT

Добавьте собственный удалённый MCP-коннектор в настройках клиента, если такая функция доступна для вашего аккаунта и региона. Адрес: `https://piratex.ai/api/mcp`, способ входа: OAuth. Это ручное подключение, не установка из официального каталога приложений.

### Cursor

Добавьте в конфигурацию MCP:

```json
{"mcpServers":{"piratex":{"url":"https://piratex.ai/api/mcp"}}}
```

### VS Code

В `.vscode/mcp.json`:

```json
{"servers":{"piratex":{"type":"http","url":"https://piratex.ai/api/mcp"}}}
```

Личный ключ, если он нужен вашему клиенту, передавайте заголовком `Authorization: Bearer` через защищённую настройку клиента. Не помещайте ключ в URL, публичный репозиторий или переписку.

## Примеры запросов

- «Найди сильные Reels в нише ремонта квартир. Покажи ссылки, просмотры и x к медиане автора».
- «Сравни последние ролики этих двух авторов. Какие темы сработали лучше их обычного уровня?»
- «Разбери этот ролик по ссылке: хук, речь, сцены и вопросы в комментариях. Предложи три идеи для моей темы».
